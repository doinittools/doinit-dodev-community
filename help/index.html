Getting started

Salesforce admin and developer tools, with the login you already have.

Quick start
  1. Log into Salesforce.
  2. Click the doDev icon in Chrome's toolbar.
  3. Pick a section – Data, Find, Compare, Monitor – and a tool.
Good to know
  • Opened on a record or user, the tool fills itself in.
  • Log into two orgs to compare them.
  • Nothing to install in Salesforce.
  • Ctrl+K searches any metadata, user or tool.
  • Tools run side by side – + opens another copy, Open tabs ▾ lists them.
  • Record Ids are links: 👁 View here or ↗ View in Salesforce.
  • ■ Stop keeps what has loaded. ↺ Restore last session reopens your tools.

doDev only reads. The one exception is Data Import, which changes only the records you confirm.

Data Explorer

Query records with SOQL, or search text with SOSL.

DataOnly reads

Guide: Query Salesforce data without writing SOQL

Quick start
  1. Pick an object – a starter query appears.
  2. Type – suggestions offer fields, values and dates.
  3. ▶ Run or Ctrl+Enter.
Use it when…
  • A record looks wrong – View formula shows how a value is worked out.
  • A save fails – the Validation rules column shows the rule.
  • "Who changed this?" – History shows who, when, old and new.
  • You have a list of Ids – Paste Ids or names.
  • 200 rows a page (up to 2,000). Filter and downloads cover every row.
  • 100,000+ rows: Download all as CSV or Load here.
  • To change many records, use Data Import.
Editor and fields picker
  • Ctrl+Space shows suggestions; Enter or Tab picks one.
  • Suggestions include related fields (Owner.), record types and relative dates (last_n_months:9).
  • ☰ Fields & relationships… picks fields, lookups (5 levels) and related lists.
  • ✨ Query Templates, History (last 100) and Saved queries are next to the editor.
  • Tooling API and Include deleted sit by the Run button.
Results and the record view
  • Sort, resize and copy any cell. Related ▾ filters by related records.
  • Excel ▾ CSV ▾ JSON ▾ copy or download what's loaded.
  • One record shows every field with its type, validation rules and history.
  • Quick links: related records, who has access, the object's page.
  • A trail at the top (‹ Back · Account › GenePoint) takes you back.
Big results
  • Rows load in parallel and are checked against the count.
  • Very many narrow rows switch to Bulk API 2.0, with a timer.
  • Over 100,000 rows (or too many to fit), you choose: download everything to a file, or load what fits.

Data Import

Insert, update, upsert or delete records.

DataWrites to Salesforce

Guide: Import, update or delete records from a CSV or Excel

Quick start
  1. Pick the object and the operation.
  2. ⬆ Import file, 📋 Paste rows or ✎ Mass update.
  3. Check the mapping and any red rows.
  4. Click Update 450 records.
Use it when…
  • Fixing a field on hundreds of records from a spreadsheet.
  • Changing every record a query finds – ✎ Mass update.
  • Loading test data, with a results file for the failures.

Deleted records stay in the Recycle Bin for 15 days; hard-deleted ones don't. Keep your file and the results CSV.

Settings and the run
  • ⚙ Settings: REST, Bulk API or Bulk API 2.0, batch size, date format, blank cells.
  • Over 100,000 rows switches to Bulk API 2.0 by itself.
  • Problems (required fields, bad values) show before anything is sent.
  • Results arrive batch by batch; ⬇ Results CSV has every Id or error.
  • #N/A in a cell clears the field.

Compare Metadata

What differs between two orgs before a deployment – code, objects, access, OmniStudio, settings?

CompareOnly reads

Guide: Compare Apex and metadata between orgs

Quick start
  1. Pick two orgs.
  2. Under What to compare, pick a type in the empty line – then check All, or give names (separated by commas, or search). Each type adds a new line.
  3. Or ⬆ Compare with a package.xml – its components fill the lines.
  4. Compare metadata
Use it when…
  • Before a deployment – just what your package.xml lists.
  • Finding hotfixes made only in production.
  • A profile, an object or an OmniScript differs between sandbox and production.
  • Types: Apex, triggers, Visualforce, LWC, Aura, flows, page layouts, Lightning pages, objects, profiles, permission sets and groups, OmniStudio (OmniScripts, Integration Procedures, FlexCards, Data Mappers), labels, custom metadata and settings, named credentials, remote sites and org settings.
  • One tree like a project: M changed, a coloured dot for only in one org, = identical. Components you name are always listed – identical ones too – and the first one with a difference opens.
  • An object is a folder (fields, record types, rules, triggers, flows, layouts); a profile or permission set is a file per kind of permission. Compare this … in detail › and Open the detailed object comparison › open Compare Profiles & Permissions or Compare Objects.
  • Search the tree for a component, a file in one, or text inside it. Single-value types (org-wide defaults, password and session policies, remote sites…) show as one table with All · Changed · Same · Only in … tabs.
  • Flows, layouts and pages are read one by one: checking All for them says it takes time. An object's layouts are read when you open them (marked ? until then).
  • Export has what the view shows: the status of each component and file, +added −removed lines (where the code was opened or is already read) and each setting that differs.
  • Org settings (org-wide defaults, roles, password and session policies, IP ranges, connected apps, organization) are types here – Compare Org Settings is part of Compare Metadata now.

Compare Users

Guides: Compare two users · A user in two orgs · What everyone in a role or profile has

Quick start
  1. Compare: Users – pick 2–5 users, from any orgs. Or All users in a profile / All users in a role – pick the profile or role.

Troubleshooting

"Your Salesforce session has expired"
Log in again, then ⟲ Restart this tool.
"You are logged into more than one org"
Click the doDev icon from a tab of the org you want.
"Salesforce didn't answer within 150 seconds"
Ask for less at once and try again.
"This org has used up its API requests"
Wait and try later – doDev warns you past 90%.
Something unexpected
Check the log (terminal icon) and report it – without Salesforce data.

Privacy and your data

Everything runs in your browser. Nothing is sent to us or anyone else.

  • doDev talks only to your own Salesforce org, with your login. No tracking.
  • Saved queries and settings are encrypted on your computer – never Salesforce records.
  • Org details stay in memory only and are forgotten when you close or refresh.
  • Clear everything under 🔒 Your data in the footer. Full privacy policy.
